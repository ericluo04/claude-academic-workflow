# Skills

32 skills + 4 sub-agents + 3 hooks. Each skill is a self-contained `SKILL.md` file in its own directory.

Most skills are venue-agnostic. The ones that touch Notion, Telegram, or the user's filesystem read placeholders from `~/.claude/state/personal_config.json` at runtime. See [`_config/README.md`](_config/README.md) for setup; an example config lives at [`_config/personal_config.example.json`](_config/personal_config.example.json).

For attribution and source credits, see [`../ATTRIBUTION.md`](../ATTRIBUTION.md).

## Drafting and writing

- [`draft`](draft/SKILL.md) — paper-section drafts in user voice (intro / lit review / methods / empirical setting / empirics / discussion / limitations), with natbib-apa citations, `\Cref` cross-refs, `\emph` over `\textit`, and figure/table notes minipages. Output goes to dated draft files; never edits the main `.tex`.
- [`referee-response`](referee-response/SKILL.md) — R&R response letters with per-role sections (SE / AE / R1 / R2), `\textit{...}` reviewer quotes, location-pinned changes verified against the actual manuscript, "Done." for trivials, polite pushback with cited authority, and abandoned drafts preserved in `\begin{comment}` blocks. Optional `--five-q` mode applies a so-what gate to pushback paragraphs.
- [`cite`](cite/SKILL.md) — resolve a paper (DOI, arXiv ID, title, URL) via Semantic Scholar / OpenAlex / arXiv MCPs, file it in Zotero via the Web API, append a Better-BibTeX entry to the active project's `.bib`, and return the citation key ready for `\citep{}`.
- [`bibcheck`](bibcheck/SKILL.md) — per-entry audit of a `.bib` against DOI / Semantic Scholar / OpenAlex / arXiv / Zotero, with one focused subagent per entry. Catches wrong years, swapped title-author pairs, fabricated DOIs, hallucinated entries. Read-only — writes a separate `corrected.bib` for review. (adapted from [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools))
- [`litreview`](litreview/SKILL.md) — multi-source literature search across arXiv / Semantic Scholar / OpenAlex (Crossref fallback), dedupes by DOI / arXiv ID / fuzzy title, scores 1–5 for relevance, and emits a ranked summarized list. Optional `--four-axis` mode replaces the single score with Novelty / Credibility / Relevance / Actionability composite.

## Reviewing

- [`review-paper`](review-paper/SKILL.md) — 6-agent pre-submission referee report tuned to a target journal (MKSCI, JMR, JCR, MS, QJE, AER, JF, RFS, etc.). Covers spelling/style, internal consistency, unsupported claims, math/notation, tables/figures, and an adversarial top-journal evaluation. (adapted from [claesbackman/AI-research-feedback](https://github.com/claesbackman/AI-research-feedback); buried-contribution gate from [aspi6246/Claude-Code-Presentation](https://github.com/aspi6246/Claude-Code-Presentation))
- [`review-paper-light`](review-paper-light/SKILL.md) — fast 2-agent gut check for an empirical paper. Focuses on contribution, identification, and causal overclaiming. ~1 minute. (adapted from [claesbackman/AI-research-feedback](https://github.com/claesbackman/AI-research-feedback); buried-contribution gate from [aspi6246/Claude-Code-Presentation](https://github.com/aspi6246/Claude-Code-Presentation))
- [`review-paper-code`](review-paper-code/SKILL.md) — reproducibility + code-quality audit. Extracts the paper's main empirical claims, compares paper to code, writes a constructive markdown report. (adapted from [claesbackman/AI-research-feedback](https://github.com/claesbackman/AI-research-feedback))
- [`seven-pass-review`](seven-pass-review/SKILL.md) — seven-pass adversarial manuscript review across abstract / intro / methods / results / robustness / prose / citations lenses, each as a parallel subagent, then a synthesis pass with 80 / 90 / 95 quality thresholds. Higher-cost than `/review-paper`. (adapted from [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow))
- [`audit-reproducibility`](audit-reproducibility/SKILL.md) — cross-check every numeric claim in a manuscript against the actual R / Python outputs, with PASS / FAIL per claim against numeric tolerances. Single-language. (adapted from [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow) and [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools))
- [`referee2`](referee2/SKILL.md) — adversarial cross-language replication audit. Reimplements R code in Python (or Python in R), compares to 6 decimal places, files a formal referee report. Stronger than `/audit-reproducibility` because it does not trust the original language at all. (adapted from [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools))
- [`council`](council/SKILL.md) — spawn up to 5 independent critic subagents in parallel on a target (idea / draft / R&R / grant / plan / skill), then run a separate synthesis pass with explicit non-majority-vote discipline. Default roster: skeptic / pre-mortem / methodologist / academic-editor / harsh-referee. `--chef-skill` swaps in a skill-design roster. (adapted from [chrisblattman/claudeblattman](https://github.com/chrisblattman/claudeblattman))
- [`blindspot`](blindspot/SKILL.md) — peripheral-vision audit of a single figure or table using a four-quadrant grid: Unexplained Feature / Convenient Absence / Unasked Question / Unexploited Strength. Figure-level only — pairs with `/seven-pass-review` (manuscript-level). (adapted from [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools))
- [`review-grant`](review-grant/SKILL.md) — 6-agent pre-submission panel review for a grant proposal targeting a specified funder (NSF, NIH, ERC, foundation). (adapted from [claesbackman/AI-research-feedback](https://github.com/claesbackman/AI-research-feedback))
- [`review-pap`](review-pap/SKILL.md) — 6-agent pre-submission review of a pre-analysis plan for a specified registration target or journal. (adapted from [claesbackman/AI-research-feedback](https://github.com/claesbackman/AI-research-feedback))
- [`evaluate-idea-marketing`](evaluate-idea-marketing/SKILL.md) — 8-step iterative pre-execution evaluation of a research idea against the MKSCI / JMR / JCR / MS bar, with lit-review threat search, citation verification, and pivot loop until the idea scores >= 7/10.
- [`evaluate-idea-science`](evaluate-idea-science/SKILL.md) — same shape, against the broad general-science bar (PNAS, Nature Human Behaviour, Nature, Science). Cross-field threat search; flags marketing-jargon contamination.

## Slides and figures

- [`academic-pptx`](academic-pptx/SKILL.md) — content and structure decisions for academic PowerPoint presentations (conference talks, thesis defenses, seminar slides, grant briefings). Governs CONTENT; pair with a `pptx` skill for the file-editing mechanics. (adapted from [Gabberflast/academic-pptx-skill](https://github.com/Gabberflast/academic-pptx-skill))
- [`academic-slides`](academic-slides/SKILL.md) — build Beamer-inspired academic HTML presentations from scratch or by converting PowerPoint files. Supports theorem environments, KaTeX, algorithm pseudocode, citations. Helps the user pick a visual theme through Beamer-style previews. Beamer-flavored HTML slides with KaTeX (adapted from [zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides))
- [`create-lecture`](create-lecture/SKILL.md) — scaffold a new Beamer lecture or research talk `.tex` from source papers / notes / prior decks, with notation consistency against the project preamble. Two modes: research-talk and pedagogical-lecture. Optional `--triage` pre-write gate. (adapted from [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow); `--triage` gate from [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools))
- [`slide-excellence`](slide-excellence/SKILL.md) — multi-agent comprehensive Beamer slide review (visual + pedagogy + proofreading, plus TikZ if present). Spawns `slide-auditor`, `pedagogy-reviewer`, `proofreader`, and conditionally `tikz-reviewer`. (adapted from [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow); pedagogy lenses from [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools))
- [`tikz-iterate`](tikz-iterate/SKILL.md) — iteratively refine a TikZ diagram: compile, render to PNG, ask the `tikz-reviewer` subagent to judge, apply fixes, repeat until APPROVED or 5 iterations. Cross-platform (MiKTeX / MacTeX / TeX Live). (new — concept inspired by [scunning1975/MixtapeTools](https://github.com/scunning1975/MixtapeTools)'s `/tikz`)
- [`posterskill`](posterskill/SKILL.md) — generate an HTML conference poster from a paper and project website, printable to PDF. (adapted from [ethanweber/posterskill](https://github.com/ethanweber/posterskill))

## Empirical and methodological discipline

- [`preregister`](preregister/SKILL.md) — draft an AsPredicted, OSF, or AEA RCT Registry preregistration document from a study spec or free-form description, annotated with MUST / SHOULD / MAY flags. Writes structure and prose; the user uploads. (adapted from [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow))
- [`replication-package`](replication-package/SKILL.md) — bundle a journal-ready replication archive (code + data + output + environment + manifest) for MKSCI / JMR / JCR / MS, sanitized and zipped. Surfaces secrets / PII / absolute paths before zipping.

## Workflow: Notion + Telegram + Zotero

- [`log-todo`](log-todo/SKILL.md) — mid-session task capture. Drop a one-liner into chat (`todo: ...`, `remind me to ...`, `log this: ...`), the skill parses inline P/min/type tags, infers Type / Project / Context, and writes a row to the Notion Tasks DB.
- [`daily-brief`](daily-brief/SKILL.md) — build the morning task brief: pull open tasks from the Notion Tasks DB, score (priority * urgency * type-balance * energy * wait-factor), pick the top 3–7 that fit available time, push to Telegram, and save `today_brief.json`. (incorporates wait-factor + type-balance scoring patches from [chrisblattman/claudeblattman](https://github.com/chrisblattman/claudeblattman); atomic-write discipline from same)
- [`capture`](capture/SKILL.md) — poll Telegram for new messages and translate them into Notion writes: `"N done"`, `"N push thu"`, `"N drop"`, `"add: ... P2 30min #research"`, `"morning 4"`, plus free-form natural-language adds. (atomic-write discipline patches from [chrisblattman/claudeblattman](https://github.com/chrisblattman/claudeblattman))
- [`task-pulse`](task-pulse/SKILL.md) — read-only ad-hoc queries against the Notion Tasks DB: "what's open for X", "what's due Friday", "anything stale", "any P0 tasks". Never writes.
- [`notion-log`](notion-log/SKILL.md) — append-only end-of-session diary entry to a project page in Notion. Per-project page mapping from config; refuses to write to Weekly Agenda / Tasks DB / personal pages.
- [`notion-meeting-notes`](notion-meeting-notes/SKILL.md) — pull a Notion AI meeting-notes page, extract `### Action Items`, keep only the items owned by the user, file each as a new Notion task with inferred Priority/Type/Project/Due. Includes a hollow-transcript gate so a wrong URL won't silently file 0 tasks. (hollow-transcript gate adapted from [chrisblattman/claudeblattman](https://github.com/chrisblattman/claudeblattman))

## Meta and skill-craft

- [`skill-creator`](skill-creator/SKILL.md) — create new skills, modify existing ones, run evals, optimize trigger descriptions. Includes a catalog-conflict gate that warns before a new SKILL.md would near-duplicate an existing one. (catalog-conflict gate adapted from [chrisblattman/claudeblattman](https://github.com/chrisblattman/claudeblattman))
