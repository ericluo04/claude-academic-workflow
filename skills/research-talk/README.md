# research-talk

Authors a research-talk deck on the Editorial theme (`slide-tooling/_extensions/editorial/`): a white page, one vermilion accent, full-bleed section slides, hand-planned clicks, a Takeaways close, and backup slides behind buttons with fixed-return Back links. The rendered example is `docs/talk/talk.html`, built from `examples/research-talk/talk.qmd`.

Credits. Deck architecture and the review-before-the-talk discipline are adapted from the `slide-excellence` orchestrator and its review agents in Pedro Sant'Anna's [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow).
